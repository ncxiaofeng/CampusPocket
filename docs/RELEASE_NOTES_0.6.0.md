# 冻小梨 0.6.0

- **学习通作业 / 考试 / 签到提醒**：内嵌学习通官方登录页，原生读取课程、作业、考试和进行中的签到活动；后台每 15 分钟检查签到，发现新签到或新待完成作业/考试时发本地通知。只读，不代签、不代交。
- **慧生活798 原生接入**：手机号 + 图形验证码 + 短信登录；查询端读取钱包余额、收藏设备和最近消费；设备端可一键启动/停止饮水设备（启动前二次确认）。同时保留支付宝小程序入口。
- **电费登录修复**：电费页改为直接打开宿舍缴费首页完成登录，保存 xgwx 会话；返回 App 后自动同步并清除旧错误提示；CAS 登录页自动勾选「一周内免登录」。
- **可选自动登录**：在「更多 → 自动登录」中主动开启后，用 Android Keystore 加密保存统一认证账号密码；会话失效时自动提交 CAS 登录表单。默认关闭，退出登录或关闭开关会删除密文与密钥；遇到验证码/二次验证会回退手动登录。
- **启动自动检查更新**：「关于」里新增开关，默认开启；每次打开 App 自动检查一次 GitHub Releases，发现新版本时弹窗提示。
- **通知权限**：Android 13+ 首次进入学习通提醒页会请求通知权限。

注意：

- 学习通提醒依赖后台任务，系统省电策略可能把 15 分钟检查推迟几分钟；签到窗口很短时请以学习通 App 为准。
- 慧生活「设备控制」需要单独再做一次短信登录，与查询端 Token 不同。
- 自动登录只在本机、App 打开或电费同步时触发，不会在后台偷偷上传密码。

## 2026-11-01 反馈修复

- 数据同步：从登录页返回后自动清除旧错误并重试；修复“登录页已登录、同步仍说过期”的 30 秒冷却问题；WebView Cookie 按 path 分开保存（JW=/jwglxt、CAS=/authserver、xgwx=/app），避免 `/sso` 与 `/jwglxt` 两个 JSESSIONID 互相覆盖；落库改用进程级协程，返回过快也不会丢会话。
- 学习通：作业/考试按本学期优先排序，列表显示服务端状态（待完成、待批阅、已完成等）；新增两种页面结构的兜底解析。
- 天气：降水改为“降水概率”，今日/明日同时显示天气现象（如“阵雨 · 降水概率 100%”），并注明 Open-Meteo 为模型预报；新增「位置」选择（当前位置/广兰/青岚/抚州），选择会保存。
- 慧生活798：修正设备控制登录签名盐（之前误用了积分任务盐，导致“验签失败”）；查询登录不显示设备时明确提示需要“设备控制”登录，并容错展示钱包/消费。

- 同步页新增「复制诊断」：包含错误、网络状态、JW Cookie 名称/path、CAS 更新时间与换票结果，便于定位“登录后仍过期”。
- 学习通状态改为高对比度色块（文字统一用 onSurface），待完成/待批阅/已完成在浅色和深色主题下都更清楚。
- 慧生活设备读取失败时显示服务端 code/msg，并提供「复制错误」。

## 发布方式变更（重要）

- 电费 `operatorPwd`、U净 HMAC key、慧生活设备登录盐不再编进 APK。
- 升级后首次使用电费 / U净 / 慧生活设备控制前，请打开 **更多 → 高级配置**，把电脑上 `local.properties` 里的三行复制到手机剪贴板，点「从剪贴板导入」并保存。
- 这些值只保存在本机，用 Android Keystore 加密；APK 和公开仓库不包含明文。
