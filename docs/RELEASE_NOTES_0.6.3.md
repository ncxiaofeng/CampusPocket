# 冻小梨 0.6.3

## 慧生活798

- **扫码设备真实名称与区域信息**：改用只读 `/dev/view?id=...` 接口并校验返回 ID 匹配，补全未收藏扫码设备的真实设备名（如 `16-1-9`、`16-1-8`）及区域副标题，并本地持久化缓存。
- **按设备类型区分图标与确认提示**：吹风机显示暖橙风筒图标、直饮水显示青色水滴图标、淋浴显示蓝色淋浴图标、洗衣显示洗衣机图标；修正吹风机与直饮水共用 `btype=3` 时的图标误判；启动二次确认弹窗按设备类型给出对应提示。
- **支持自定义备注**：点击设备名称可随时修改备注，留空可恢复接口默认名称。

## 学习通

- **默认进入「阅读版」原生前端**：打开作业 / 考试页面默认展示液态玻璃阅读卡片（标题、成绩/正文与页面操作按钮），隐藏底层 WebView 避免画面穿透；需要作答、签到或查看原始排版时，点右上角「原网页」或「浏览器」即可一键切换。
- **修复原网页异常缩放**：开启宽视口自适应、双指缩放与混合内容兼容，仅在页面 `rem` 基准异常放大时按 750 设计稿比例折算，不再压扁原有按钮与布局。

## 底部导航栏

- **移除点击阴影 + 可自由滑动液态玻璃滑块**：去掉 Material 默认灰色点击阴影，新增触摸浮起的液态玻璃透镜滑块，支持跨中央 `+` 按钮左右自由滑动并实时高亮下方 Tab 与触觉反馈。
- **满帧零重组跟手**：拖动过程直接驱动 GPU `graphicsLayer` 平移（不触发底栏与背景模糊层重组），点击切页与松手吸附配合柔和液态弹簧与轻微形变。
- **修复冷启动切页后无法点回首页**：修复 `pointerInput` 闭包捕获旧 `selectedIndex` 导致切去其他 Tab 后点不回首页的问题。

## 电费与后台无感自动登录

- **修复电费 30 天视图每月 1～9 号空白**：`xgwx.ecut.edu.cn` 的 `/app/app/api/data/dosage` 接口要求补零日期 `yyyy-MM-dd`，改用 `ISO_LOCAL_DATE` 格式并结合缺失日逐日补查与会话自动恢复，30 天数据连续无缺口；首页返回前台自动静默刷新。
- **完善后台无感自动登录**：支持统一身份认证（CAS）与零信任门户（aTrust）后台自动重登，修复同名跨路径旧 Cookie 遮蔽问题；自动登录页新增「测门户」验证，WebView 官方页遇到登录跳转可静默恢复后自动回到目标页。

## 其他细节

- 补齐首页学习通、慧生活798 账户/钱包、自动登录等卡片的 Material 图标映射，消除网格占位图标。

## 说明与限制

- 电费 `operatorPwd`、U净 HMAC key、798 设备登录盐仍不编进 APK；公开版需在本机「高级配置」中自行导入。
- 仍坚持只读与安全边界：学习通不代签、不代交作业；798 仅扫码设备允许二次确认后启动，不提供停止与充值。

## 验证

- 单元测试：16 个测试套件共 69 项测试全部通过（含电费补零日期与缺日补查、798 名称/类型解析、CAS/门户自动登录与 Cookie 路径去重、底栏滑块几何计算）。
- 实机验证（RMX3888，校园网环境）：电费 30 天视图恢复连续 29 天完整数据；798 正确显示 `16-1-9` / `16-1-8` 真实名及吹风机/直饮水/淋浴图标；学习通默认进入阅读版且排版正常；底栏冷启动切页回首页与跨 `+` 滑动跟手顺滑。
