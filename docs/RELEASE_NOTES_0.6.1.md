# 冻小梨 0.6.1

## 首页

- 电费模块只在配置了电费参数时显示；未配置时自动隐藏，不再占首页位置。
- 新增「学习通」首页卡片：显示进行中签到、待办作业/考试和最近一条待办。
- 新增「慧生活798」首页卡片：显示钱包余额、设备数量、在线/使用中数量和最近一笔消费。
- 电费配置后，首页顺序为：学习通 → 慧生活798 → 电费 → 校园卡。

## 慧生活798

- **只有扫过设备二维码的设备才显示「启动」**；没扫过的设备只读状态，避免随手启动别人的设备。
- **移除停止功能**，只保留启动；启动前仍需二次确认。
- 页面在前台时每 10 秒刷新设备状态：在线 / 使用中 / 启动中 / 离线 / 禁用；使用中、启动中、离线、禁用时都不显示启动。
- 新增相机扫码：按需申请相机权限，二维码只在本地识别，不上传图片。
- 支持纯设备编号、`ilife798s://...`、`/q/...?id=`（自动走 `/qr/use` 换设备号）和带 `id/did` 的链接。

## 高级配置

- 新增「扫码导入配置」：可以扫一张包含三项 `key=value` 或 JSON 的二维码，自动填入电费 / U净 / 798 设备盐。
- 新增「打开今日校园查电费」：未配置电费时，电费页和缺少配置页可以直接打开今日校园；未安装时跳应用商店/网页。
- 电费链接导入仍保留，但今日校园内的缴费页不能直接导出链接；如手上已有带 `operatorPwd` 的完整链接，可以粘贴导入。

## 说明与限制

- 电费 `operatorPwd`、U净 HMAC key、798 设备登录盐仍不编进 APK；公开版需要本机配置。
- 配置二维码含共享参数，请只私下发给信任的人，不要上传公开群、网盘或仓库。
- 798 的“扫码后才能启动”是客户端产品规则，不是服务端权限校验；服务端若校验设备归属，以服务端结果为准。
- 状态轮询依赖网络；页面退到后台会自动暂停。

## 验证

- 单元测试：设备编号解析、状态映射、电费链接解析、配置文本解析全部通过。
- K40 实测：学习通卡片显示待办数、798 卡片显示余额/设备/最近消费，点击均能进入对应页面；798 设备状态显示「在线」；扫码页和高级配置页正常打开。
- 尚未实测：真实设备二维码启动、设备使用中时隐藏启动、今日校园已安装时的跳转。
