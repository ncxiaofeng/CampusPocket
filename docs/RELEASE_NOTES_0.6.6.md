# 冻小梨 0.6.6（Android & iOS 双端版本号对齐）

## 自定义课表与自定义考试

- **自定义课程**：在「课表」页右上角点 `+` 可手动添加自定义课程（课程名、星期、起止节次、周次区间/单双周、校区、教室、教师），支持点击详情随时编辑或删除。
- **自定义考试**：在「课表」页或「考试安排」页点 `+` 可手动添加自定义考试（考试科目、日期、起止时间、校区、考场、考试类型、座位号、备注），支持随时编辑或删除。
- **教务同步永不覆盖自定义项**：Android 端 Room 数据库显式升级（v4 → v5 保留全部已有登录态与数据），iOS 端同步合并持久化；同步教务课表或教务考试时自动保留全部自定义课程与自定义考试。

## 考试融合显示在课表与首页

- **周课表融合展示考试**：落在该周的教务考试与自定义考试，按起止时间自动映射到对应星期与节次，以醒目绯红高亮卡片 + 「考试 / 考·自」角标叠放在课表顶层，点击可查看完整考场与座位信息（自定义考试可直接编辑/删除）。
- **首页联动提示今日考试**：首页「今日课程」卡片自动合并展示当日考试，并用醒目「考试」角标高亮提醒。

## 剪贴板消息 & 截图离线智能识别（人工审核后加入）

- **剪贴板智能解析**：复制班级群/通知里的加课、补课、调课或考试消息，点击 `+ → 从剪贴板智能识别`，纯本地规则引擎自动识别类型（加课 / 考试）、日期/相对日期（如「下周三」「1月8日」自动跨年）、周次、节次/时钟、校区、教室/考场、教师与座位号，支持一次拆出多条。
- **截图离线 OCR 识别**：
  - Android 端内置离线中文 OCR（ML Kit Text Recognition Chinese）并采用系统照片选择器（无需全局存储权限），按视觉行序整理表格与通知文字；
  - iOS 端采用原生 `PHPickerViewController` + `Vision.framework` 离线中文识别（零第三方依赖、零体积增长）；
  - 全程 100% 本地离线处理，不上传任何截图或聊天记录。
- **本人修改审核流**：识别出的全部草稿会进入「智能识别审核」弹窗，支持展开微调 OCR 原文重新解析、逐条切换类型（加课 ⇄ 考试）、编辑任意字段或取消勾选，经本人点击「确认加入」后才写入本机；面对高校多班级分考场考试表时自动按考场拆分为独立待选条目，并展示班级号辅助筛选。

## 节假日调休 / 调课（Android & iOS 双端）

- **调休补课（改上某天课）**：在课表页 `+ → 节假日调休 / 调课` 可设置某天（如周六/周日）改上另一天的课表（跨周与单双周自动准确换算），并默认一键将原课程日期设为放假停课。
- **放假停课（单日或连休多日）**：支持直接设置连续放假区间（如国庆 7 天连休），当天课表列显示「休 / 放假停课」提示，且不影响当日考试展示。
- **剪贴板识别放假调休通知**：支持直接复制学校放假调休通知，一键解析出全部放假区间与补课对调规则，核对后批量应用。
- **无损生效、随时撤销**：调休规则独立持久化，教务同步不会覆盖；同时联动周课表网格（「调」「休」角标 + 本周调休提示条）与首页「今日课程」卡片，撤销即可秒回原课表。

## 慧生活798 登录协议适配与稳定性优化

- **默认设备控制端登录（v3.1.9）**：适配慧生活798 服务端近期下线旧查询通道的变更，Android 与 iOS 双端登录页默认切换为「设备控制端」，一次登录即可查余额、设备状态、账单并支持扫码启停。
- **修复 iOS HTTP 请求头大小写兼容**：修复 iOS 端发送设备控制端签名请求时标准客户端自定义头被转为小写导致验签异常的问题，实测 Android 与 iPhone 均一次登录成功。
- **暗色模式底栏细节优化**：修复 Android 暗色模式下底部液态玻璃导航栏及滑动透镜滑块顶部出现灰白横线的问题。
- **放假调休通知智能解析增强**：兼容高校正向/反向/成对「分别」/按星期调课以及国务院放假调休通知格式，并按段落准确区分各节日标签。
