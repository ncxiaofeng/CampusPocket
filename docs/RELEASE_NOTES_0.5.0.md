## 冻小梨 0.5.0

本次更新集中修复数据准确性与界面可读性，并加入天气预告和液态玻璃主题。

### 首页
- 新增「校园天气」：基于 Open-Meteo 公开接口，展示当前温度、体感、湿度、风速、今明两天高低温与降水概率；有课时按上课时间匹配逐小时预报。
- 校园卡模块升级：显示余额、本月消费/充值金额与笔数，以及最近 3 笔消费流水，点按进入完整校园卡页。
- 电表余额修复：余额现在写入接口实际返回的最新用量日；首页不再长期显示「-- 元」。

### 电费
- 修复近 30 天视图里历史日期显示 0.0 度的问题：接口未结算/超出保留期的日期显示为空白圆点，不再伪造 0 度。
- 同一天只保留一条采样，避免反复同步把更早历史挤出缓存上限。
- 余额卡片补充更新时间，同步后可立即看到余额。

### 课表
- 顶部改为「第 X 周 / 周几 / 本周日期」，左右箭头切换周次，不再占用一整行周次卡片。
- 网格按屏幕剩余高度自动分配 1–10/12 节行高，铺满页面，减少无谓留白与滚动。
- 课程块改为高饱和底色 + 白色文字，字体放大，优先显示课程名、教室和教师；所有课程同校区时不再重复显示「广兰校园」。
- 今天日期用圆形高亮，左侧节次号与上下课时间同步放大。

### 界面与图标
- 全局改为类 HyperOS / iOS 的液态玻璃风格：渐变光斑背景、半透明玻璃卡片（顶部镜面高光、底部内阴影、带青/紫色散的描边）、悬浮玻璃底栏，支持深色模式。
- 底栏改为「首页 / 课表 / 校园卡 / 更多」四栏 + 中央绿色「+」按钮；点“+”弹出液态玻璃快捷服务面板（数据同步 / 电费 / 校园卡 / 空闲教室 / 图书馆 / U净洗衣）。
- 新增「校园卡」一级 Tab，首页校园卡卡片与底栏共用同一入口。
- 所有服务图标改为 Material 图标；未知标识统一回退到通用图标，不再把单个汉字当图标。
- 修复部分二级界面（占位页、账号卡片、登录提示）仍使用单个汉字作为图标的问题。
- 官方网页页标题栏压缩按钮，避免「刷新」被挤成两行。

### 说明
- 天气数据来自 Open-Meteo，仅发送广兰校区固定坐标，不携带账号、学号或设备标识。
- 学校电费接口只保留近期日明细，因此 30 天视图可能出现空白日期，属于数据源限制。
