# 冻小梨 0.6.4

## U净洗衣（公开版免配置 + 精准定位）

- **官方网页免配置登录**：U净洗衣不再需要手动配置 `ujing.hmac.key`。登录页内嵌 U净官方网页发送验证码，底部使用手机号 + 验证码直接完成登录并保存约 90 天会话，公开安装包开箱即用。
- **修复附近洗衣房定位偏移**：Android 原生 GPS（WGS-84）与 U净门店坐标（GCJ-02）存在约 600 米偏移，新增本地坐标纠偏与定位时效/精度筛选，并按实际距离升序排序，可准确识别所在楼栋附近门店。

## 慧生活798（查询免配置 + 本人设备安全停止）

- **查询登录设为默认免配置入口**：未配置设备登录盐时，可直接登录查询钱包余额、已绑定设备状态与消费记录；切到「设备控制」时提供明确引导，不浪费短信验证码。
- **支持安全停止本人启动的设备**：仅当通过本机 798 设备端启动且处于运行中（30 分钟内本机发起或服务端使用人匹配本人）时，才显示「停止」按钮并要求二次确认；他人正在使用的设备绝不显示停止入口。

## 统一身份认证（CAS）修复

- **修复首次登录表单反复刷新**：无有效主凭据（`CASTGC`）时，不再向登录页预注入陈旧的 `route` / `JSESSIONID` Cookie，避免输入账号密码时页面异常重置。
- **自动升级明文 HTTP 跳转为 HTTPS**：拦截统一认证域名的明文 `http://` GET 跳转并升级为 `https://`，解决部分校园网节点 80 端口返回空响应导致登录打不开的问题。

## 高级配置（一次性 / 限时安全配置码）

- **支持远程一次性（阅后即焚）与限时安全配置码**：除原有的手填与剪贴板导入外，扫码导入新增对短时效远程安全配置码的支持；校验 HTTPS 域名与路径白名单、禁止重定向且不携带校内 Cookie；一次性模式导入完成后自动销毁云端凭证，防止二次转发。
- **防明文查看锁定**：通过安全配置码导入的参数会立即以 Android Keystore AES-GCM 加密保存到本机，并在「高级配置」界面锁定展示，打开明文开关亦不会露出明文，仅允许清除后重新填写。
- **内置交流群入口**：「关于 冻小梨」与「高级配置」新增 QQ 交流群（`163103375`）一键复制入口，便于日常反馈与按需获取配置码。

## 说明与限制

- 公开 APK 与开源代码不包含任何第三方固定参数或私密凭证；U净洗衣与慧生活798 查询功能已免配置可用，电费与 798 设备启停仍按需在「高级配置」导入。
- 仍坚持纯本地运行与只读边界：学习通不代签、不代交作业；U净不代下单；798 仅允许扫码后二次确认启停本人设备，不提供充值。
