## 冻小梨 0.5.3 · U净接入设备定位

> 本版同时包含 0.5.2 的底栏与定位改造：绿色加号回到悬浮底栏内部居中；底栏通过 `GraphicsLayer + RenderEffect` 真实采样并模糊背后页面内容；天气已改用设备定位。下面重点说明本版新增的 U净定位。

### U净洗衣
- 新增「当前位置」定位来源：登录后默认按设备实际坐标查询附近洗衣房，解决固定使用广兰校区坐标导致楼栋/距离不准的问题。
- 顶部校区选择器增加「当前位置」芯片，可随时切回广兰 / 青岚 / 抚州校区；手动选择校区后停止使用设备坐标。
- 未授权定位时会沿用校区坐标；点击「当前位置」会请求定位权限，拒绝后提示并保持校区回退。
- 定位失败或系统没有可用定位时，自动回退到当前校区并给出提示。
- 「最近使用」楼栋仍然保留，可反查不在附近 10 家列表里的常用洗衣房。

### 共用定位能力
- 复用 `DeviceLocationProvider`（Android 原生 LocationManager）：
  - 天气：设备当前位置坐标（已有）。
  - U净：附近洗衣房查询（本次新增）。
- 其他后续需要定位的页面可以直接注入 `AppContainer.deviceLocationProvider`，无需重复实现权限/定位逻辑。

### 说明
- U净的设备定位只用于 `stores/near` 查询，不上传手机号、学号等个人信息。
- 定位权限仍沿用系统权限；拒绝定位不影响 U净按校区查询。
